# [설계] 전달 전 사용자 화면 기록과 MCP 공개 커서 0 분리

## 배경
현재 셸 전달 시 공개 출력 버퍼와 함께 사용자 터미널 화면도 초기화한다. MCP에서 과거 출력을 숨기기 위해 사용자 화면의 과거 기록까지 지울 필요는 없다.

## 목표
사용자는 전달 전 화면/스크롤백을 계속 볼 수 있고, MCP에는 전달 이후의 독립된 출력 스트림만 공개한다. ‘line 0’은 화면 첫 줄과 혼동하지 않도록 MCP 공개 커서 0으로 정의한다.

## 제약
- 이전 화면 스냅샷·입력·스크롤백을 MCP 출력으로 변환하거나 재공개하지 않는다.
- 사용자 표시 기록은 메모리 상한을 두고 세션 종료 시 폐기한다.
- 표시용 과거 기록을 VT parser에 재입력해서 장치 응답이나 입력이 발생하면 안 된다.
- 전달 경계의 미완성 UTF-8/ANSI 상태 처리와 단일 프로토콜 응답 경로를 유지한다.
- 이전에 생성됐으나 전달 후 도착한 네트워크 출력의 한계는 계속 명시한다.

## 완료 기준
- 사용자 화면에서 전달 전/후 경계가 구별된다.
- MCP cursor=0 조회에는 기존 표식이 없지만 사용자 화면에서는 해당 기록을 볼 수 있다.
- 기록 유지가 소유권, 키 입력 차단, 출력 상한, 종료 시 폐기에 영향을 주지 않는다.
- 화면 기록과 parser 상태를 분리하는 설계를 검토한 뒤 구현 범위를 확정한다.
