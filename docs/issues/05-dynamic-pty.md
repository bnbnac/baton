# [설계] 창 크기에 맞춘 원격 PTY 크기 변경

## 배경
현재 PTY는 120×32로 고정되어 있다. 사용자는 앱 창에 맞춰 터미널 크기가 동적으로 바뀌기를 원한다.

## 목표
화면 표시와 원격 PTY의 행·열 크기를 일치시키는 흐름을 설계한다. 화면 확대만 하고 원격 크기는 고정하는 방식과 구분한다.

## 검토할 사항
- 창/패널 크기, 글꼴 셀 크기, DPI 변경으로부터 행·열을 산출한다.
- 사용자 소유/에이전트 소유 단계에서 resize 권한과 고정 여부를 정한다.
- 변경 빈도 제한, 최소·최대 크기, 최소화·숨김 상태를 처리한다.
- resize로 다시 그려지는 출력과 MCP cursor의 의미를 정의한다.
- 화면 기록 유지와 VT parser 크기 변경의 상호작용을 검토한다.

## 완료 기준
- 일반 셸에서 원격이 인식하는 행·열과 UI가 일치한다.
- 반복 resize와 DPI 변경이 입력 중복, 출력 스트림 초기화, 메모리 무제한 증가를 만들지 않는다.
- 전체 화면 프로그램에서 재그리기와 원래 셸 복귀를 확인하는 검증 계획을 갖춘다.
- 창 크기 변경이 사용자 입력권 회수나 MCP 명령 완료 판정으로 취급되지 않는다.
