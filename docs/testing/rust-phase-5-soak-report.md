# Rust Phase 5: 2시간 부하 검증

2026-10-14, 기준 `84aae1c`에 시험 코드만 추가했다. **현재 60초 사전 시험 통과이며 2시간 릴리스 결과는 아직 미확정이다.** 승인된 검증 설계 §4와 [실행 계획](../superpowers/plans/2026-10-14-rust-phase-5-soak.md)을 따른다.

## 구성과 판정

실제 Windows 제품 UI와 최신 MCP 어댑터 32개, localhost 전용 OpenSSH 컨테이너 2개에 8개씩 연결한 SSH 셸 16개를 사용한다. UI/어댑터는 [100회 수명 검증](rust-phase-5-lifecycle-report.md)과 같은 바이너리 조합이다. 이전 ZIP에 최신 어댑터가 포함됐다는 뜻은 아니다. 실제 사용자 서버·인증·하네스 설정은 사용하지 않는다.

각 셸은 세션 번호·증가 번호·고정 payload로 된 1KiB 이상 로그를 초당 출력하고 주기적으로 4개 레코드 burst를 보낸다. 원시 출력은 공개 구간별로 검사한다. 앞선 준비 시간의 출력은 측정률에서 제외한다. 각 세션 측정 구간의 출력률은 초당 1,024바이트 이상이어야 한다. 표식이 있는 로그의 타 세션 혼입, 번호 중복·누락·역행, payload 손상, 공개 버퍼 손실과 15초 정체는 실패다. 회수 시 비공개 구간은 새 stream으로 분리한다.

분당 모든 셸에 고유 기록 명령을 보내며 send_text의 동일 request_id를 중복 전달한다. 서버 audit 파일이 기대 목록과 정확히 일치해야 한다. 선택한 탭의 레이아웃을 변경하고, MCP geometry뿐 아니라 서버 `stty size`를 직접 대조한다. 한 세션을 사용자에게 회수한 뒤 다른 어댑터에 다시 전달한다. 32개 어댑터의 online 상태와 연결 ID 유지도 분당 확인한다.

30초마다 앱·Job 내 WebView·32개 어댑터의 private bytes/working set을 합산한다. 20분 warm-up 이후 20분 구간 5개의 중앙값을 구한다. 마지막/첫 안정 구간이 어느 지표든 1.2를 초과하면 통과시키지 않고 조사 대상으로 남긴다. 이것은 누수 부재를 증명하는 기준이 아니다. 시험 실행기·Docker·PowerShell 자체의 메모리는 합산 대상에 포함하지 않는다.

정상 부하를 끝낸 뒤 별도 과부하 단계에서 32KiB를 0.1초 간격으로 40번 보내 정상 소비를 확인한다. 이어 시험 WebView의 대상 세션 ack 요청만 차단하고 동일 출력을 보낸다. 차단 관측, 대상의 agent_owned 유지 후 closed 전환, 나머지 15세션의 agent_owned 유지가 모두 필요하다. 제품 인터페이스에 close reason이 노출되지 않으므로 정확한 내부 종료 사유를 관측했다고 주장하지 않는다. 이 대조 시험은 ack 정체 시 제한된 동작의 외부 증거다. 정확한 내부 1MiB 큐 상한은 core 검증과 구분한다.

## 사전 시험

증거: `artifacts/phase5-soak-20261014/`.

- `soak-oracle.test.mjs`: 구현 전 모듈 부재 실패 확인 후 10개 통과. 데이터 혼입·번호 중복/누락/역행·payload 손상·미종결 버퍼 증가·메모리 표본 부족/20% 초과를 검증한다.
- `smoke1`: 정상 부하 60.429초와 audit 대조는 완료했으나 과부하 주입 실패. 읽기 전용 Tauri invoke 속성 교체가 적용되지 않아 droppedAcks=0. 세션이 닫혔어도 캠페인 전체 실패로 보존했다.
- 독립 검토: 과부하의 잘못된 원인 판정, 원격 resize 미검증, 준비 출력 포함/낮은 출력률 기준을 지적해 수정했다.
- `smoke2`: 60.431초 정상 부하 및 정상/차단 burst 대조 통과. 대상 ack 차단 1회, 대상 closed, 다른 15세션 생존.
- 후속 검토: 탭 재방문 때 같은 목표 폭 때문에 잘못된 timeout 가능성 발견. 측정한 geometry에 따라 다른 목표 폭을 선택하고 사전 시험에서 3초마다 전환해 재방문을 포함했다.
- `smoke3`: **60.167초 통과**, audit/resize/회수·재전달 각 20회. 세션 0~3의 재방문 포함. 두 컨테이너 제거 및 앱 정상 종료, 어댑터 32개 EOF 종료 확인. 최종 본 실행은 이 코드 기준이다.

60초 사전 시험은 2시간 메모리 판정이나 릴리스 통과에 포함하지 않는다. 실패 증거는 재실행으로 덮어쓰지 않았다. 미완성 퍼징 파일은 수정·실행·커밋 대상에서 제외했다.
